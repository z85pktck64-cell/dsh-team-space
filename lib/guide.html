01

会话上传把一段完整对话分享给团队

  1. 在左侧会话列表里，把鼠标移到某个会话上，点行尾的 ⋯。
  2. 选「分享到团队空间」。
  3. 分享的是完整对话记录，上传到主服务器；正文特别大时会自动降级成文本快照。
分享不等于「发给所有人本机」——别人要先认领，历史才会复制到他们自己的机器上。
02

会话领取把别人的会话拿到本机继续

  1. 打开「会话」tab，找到想要的那条。
  2. 点卡片上的「认领」。
  3. 插件会把完整历史复制成本机的一个新会话，并自动打开它。
  4. 看完可以点「交回」留个回执，发起人那边能看到你已认领。
认领是幂等的：重复认领会复用同一份副本，不会每次多出一条。
03

委托把活派给队友的 AI，执行完自动回传

  1. 发起：只能由 AI 发起。直接跟你的 agent 说「把这个任务派给某某」，它会调用委托工具；页面上没有手动新建按钮。
  2. 谁能看到：指定给某人的委托，只有被指定人、发起人、主服务器看得到；不指定人的对所有人可见。
  3. 接收：被指定人在「委托」tab 点「接收」→ 自动建一个新会话、把指令投进去、开始执行。
  4. 交回：执行完点「交回结果」，写清做了什么和结论。
  5. 回导：发起人这边每 20 秒检查一次，结果会导进一个新会话，可以直接接着聊。
看不到某条委托是正常现象：指定给别人的委托不会出现在你的列表里。
看不到「删除」也正常：委托只有主服务器能删，避免成员误删别人的记录。
04

SKILL 与插件共享别人写好，你一键装到本机

  1. SKILL：「SKILL」tab → 找到别人共享的正文 → 点「安装」→ 写入你自己机器的 ~/.dsh/skills/<name>/SKILL.md。
  2. 插件：「插件」tab → 清单里带审计结论 → 先读审计，再点「安装 / 更新」。
  3. 装插件是下载压缩包 + 解压 + 登记，装完通常需要重启 App。
装第三方插件前必须看审计结论：它能跑什么命令、写哪些目录、有没有网络出口。团队空间只负责分发，不替你判断安全性。
05

常见问题几个一定会遇到的点

  1. 看不到别人的委托 —— 正常，指定给某人的委托只对被指定人可见。
  2. 看不到「删除」 —— 委托只有主服务器能删。
  3. 点「接收」没反应 —— 确认团队空间页面开着，且本机配了可用模型。
  4. 会话认领后找不到 —— 它会在侧边栏会话列表里出现，标题与原会话相同。
  5. 插件显示「可更新」但本机版本更高 —— 2.7.25 起按语义化版本比较，本机 ≥ 空间会显示「已是最新 / 本机更新」。
  6. 不要在本机点「更新」团队空间自己 —— link 安装会被替换目录，运行中的 DSH 会崩。
